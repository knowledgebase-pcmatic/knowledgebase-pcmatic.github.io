PC Matic Knowledgebase — Cloudflare Pages deployment

IMPORTANT: index.html is in the ROOT of this ZIP.

Deploy: Cloudflare Dashboard > Workers & Pages > Create application > Pages > Upload assets. Upload/extract this folder so index.html is at the deployment root.

If using Git integration, upload the contents of this folder to the repository root. Set Build command to empty / none and Build output directory to the project root (.). Do not set a subfolder such as public unless you move all site files there.

Includes 700 article pages, searchable homepage, category filters, sitemap.xml, robots.txt and 404 page.

Navigation: the header contains Login and Support buttons. Login opens the supplied account portal. Support opens the dedicated support.html page; its Get Support button opens the supplied support destination.

Navigation update: Login opens the separate internal login.html page. The account portal destination is placed only on the inner button of support.html. The header has only Login and Support buttons.
